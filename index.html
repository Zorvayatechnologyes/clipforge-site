This page is the interface. The actual cutting — downloading the stream, transcribing it, finding the funny parts, rendering the vertical video — runs on a small server, because browsers cannot run ffmpeg or Whisper. Point this page at one:

1
Run it on this computer. Download and unzip the project, then double-click Start ClipForge — on a Mac it is Start ClipForge.command. It installs itself the first time and opens at http://127.0.0.1:8000; this page then connects to it automatically. On Linux, run bash run.sh.
2
Or host it once, use it from any device. The project ships a Dockerfile; deploy it to Render, Railway, Fly.io or any VPS, then paste that URL into the Engine box above. Full steps are in the README.
3
Already have it running somewhere? Paste the address — for example https://clipforge-api.onrender.com — and press Connect.
